# 九州 · 中国文明地图

参考 [usaciv](https://karpathy.ai/usaciv/) 的产品思路，用真实公开数据绘制的中国版「文明」战略地图。地图不是一个 4X 游戏，而是一个可以浏览、比较和下钻的数据可视化：**金币 = GDP，粮食/生产/科技/文化 = 就业结构，城市城区 = 真实产业特色，奇观 = 按公开规则选出的国家公园、景区、大学与地标。**

> 这是独立实现：界面与交互代码基于 usaciv 的 MIT 源码改造，数据管线、行政区划、城市数据与中国主题设计为重新构建。原项目 © Andrej Karpathy，MIT License。

## 快速开始

```bash
cd china-civ
python3 serve.py            # http://127.0.0.1:8767
```

或任意静态服务器：

```bash
cd china-civ/web && python3 -m http.server 8080
```

站点完全静态，`web/` 可直接上传到任意静态托管。

## 已实现

- **中国六边形地图**：32 个省级行政区（含台湾）、379 个地级行政单元，Albers 等面积投影（标准纬线 25°N/47°N，中央经线 105°E），25 km 半径尖顶六边形网格（122 × 123，约 15,000 格）。
- **真实地形**：AWS Terrarium/Mapzen 地形瓦片（约 2 km 分辨率），每格 7 个采样点计算海拔、起伏、山体阴影；Natural Earth 国界、湖泊、河流。
- **产出**：粮食/生产/科技/文化为就业结构，金币为 GDP（2024 年省级 GDP 校准）。
- **19 种镜头**：人口密度、GDP、人均 GDP、城镇化、老龄化、人口增长、城乡收入、住房单价、失业、学历、研发强度、森林、耕地、海拔、起伏、灾害、PM2.5、电站装机等。
- **城市视图**：点击城市查看市民（职业/年龄/通勤/教育/出生地）、城区（学府、商务、工业、港口、文化、休闲、航空、政务、水利等）、经济、劳动力、资源、对比。
- **顾问团**：能源与资源、经济、人口、民生与住房、科教、土地、商贸、文化、探索器。
- **探索器**：任意层级（省/市/区县）任意列 → 表格 + 散点图，并与地图联动。
- **图鉴**：每个数字的口径、来源、方法说明；每个镜头都带 caveat。
- **分享**：URL 保存镜头/选中/位置；可下载 1600×900 PNG 分享图。

## 数据来源

| 数据 | 来源 | 用途 |
|---|---|---|
| 省级 GDP、人口、城镇化、收入、教育 | 国家统计局《中国统计年鉴》、各省统计公报（2023–2024） | 省级面板、收入/城镇化镜头 |
| 地级市 GDP、人口、产业结构 | 《中国城市统计年鉴》、各市统计公报（2019–2024 最新可得） | 城市产出、城市视图、探索器 |
| 台湾地区省级与城市数据 | 台湾地区统计部门及公开年鉴（2023–2024，近似整理） | 台湾覆盖与城市分配 |
| 行政区划边界与中心 | 阿里云 DataV GeoAtlas（2024） | 省/市边界、六边形归属、城市定位 |
| 高程 | AWS Terrarium / Mapzen 地形瓦片（约 2 km） | 海拔、起伏、阴影 |
| 国界、陆地、湖泊、河流 | Natural Earth 1:50m | 底图与地理上下文 |
| 电厂 | WRI Global Power Plant Database | 电厂点位、装机、能源镜头 |
| 港口 | 交通运输部 2023 年港口吞吐量 | 前 20 港口 |
| 机场 | 中国民航局 2023 年旅客吞吐量 | 前 30 机场 |
| 国家公园 / 5A 景区 / 大学 / 地标 | 国家林草局、文旅部、教育部与高校预算公开、UNESCO | 奇观规则 |
| 重大灾害 | 应急管理部、中国地震台网、气象局公开记录 | 灾害镜头（近似指数） |
| 土地覆盖 | 生态分区模型（气候带 + 高程 + 城市距离，按省级森林覆盖率校准） | 地图底色、森林/耕地镜头 |

> 完整来源、URL 与口径见站内「图鉴 → 数据来源」。

## 数据口径与边界

- **不是官方统计产品**：省级 GDP/人口为公开统计整理；地级市部分年份不齐，已按省级总量校准；城市内部人口/GDP 的空间分布、就业结构、收入、房价等无法逐市公开获得的指标由模型估算，面板和图鉴已标注。
- **不含港澳**：当前范围为 32 个省级行政区（大陆 31 个 + 台湾地区），香港、澳门暂未纳入；台湾地区数据按公开统计另行整理。
- **土地覆盖不是遥感分类**：为生态分区模型生成，并用各省森林覆盖率校准；适合视觉浏览，不适合作为科研数据。
- **灾害为记录次数**：不是损失金额，也不是风险概率。
- **地图位置是示意**：城区图标位置、道路/铁路走向均为示意，不代表精确坐标。

## 重建数据

```bash
cd china-civ
python3 -m pip install numpy pandas pillow matplotlib pypinyin lxml
python3 build/build_all.py
```

构建会读取 `build/cache/` 下的边界、地形瓦片、统计中间文件；首次构建会自动下载地形瓦片。统计数据来自 `build/cache/province_stats.json` 与 `prefecture_stats.json`，由 `build/prepare_stats.py` 从公开统计表整理。
